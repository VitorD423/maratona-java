# Atividades Java

Esta pasta reúne algumas atividades práticas que fiz durante meus estudos de Java.

Os exercícios serviram para praticar conceitos como:

- Criação e manipulação de objetos.
- Encapsulamento com getters e setters.
- Associação entre classes.
- Separação de responsabilidades usando classes de serviço.
- Criação e cópia de objetos.

Cada atividade possui seu próprio código e foi desenvolvida para praticar os conceitos estudados durante o curso.
