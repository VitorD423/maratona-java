# Maratona Java ☕

Repositório criado para guardar meus estudos e exercícios durante meu aprendizado de Java.

Aqui compartilho códigos e exemplos dos assuntos que venho estudando, desde os conceitos básicos até tópicos mais avançados da linguagem.

A ideia é praticar, revisar o conteúdo e acompanhar minha evolução como desenvolvedor Java.

## Conteúdos estudados

- Fundamentos da linguagem Java
- Variáveis, operadores e estruturas de controle
- Métodos, construtores e encapsulamento
- Programação Orientada a Objetos
- Herança e polimorfismo
- Classes abstratas, interfaces e enums
- Tratamento de exceções
- Wrappers e manipulação de Strings
- Datas e horários com a API Date/Time
- Manipulação de arquivos (IO e NIO)
- Collections e Maps
- Generics e Wildcards
- Classes internas e anônimas
- Stream API e Collectors
